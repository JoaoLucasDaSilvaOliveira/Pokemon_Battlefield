# Pokemon_Battlefield
    Projeto de conclusão da matéria de Prog I e II
    Final Project for Programming I and II

    Intruções:
        - Este projeto é baseado na linguagem C.
        - Salve todos os arquivos no mesmo diretório.
        - A base de dados foi projetada com manipulação de arquivos, logo não é necessário inserir dados iniciais ou alterar os dados inseridos! Caso exclua todos os arquivos da base de dados, ela se regenerará com           o nome do arquivo e conteúdos originais.
        - Caso queira, podes mudar a base de dados nos arquivos txt como Treinadores.txt. 
        - ! Só modifique o conteúdo do arquivo, de forma ordenada, de preferência apenas as chaves e valores já existentes. Caso queira adicionar novas chaves e valores, siga a arquitetura existente. !
        - O projeto trabalha com ponteiros e referências de memória, por isso tome muito cuidado com as mudanças de arquivos, nomes e diretórios.


    Instructions:
        - This project is C based.
        - Save all the archives on the save diretory.
        - The database is managed through file manipulation, so there is no need to insert initial data or modify the stored data! If you delete all database files, they will regenerate with their original names              and contents.
        - If desired, you may modify the database files, such as Treinadores.txt.
        - ! Only modify the file content in an orderly manner, preferably just the existing keys and values. If you wish to add new keys and values, follow the existing structure. !
        - The project uses pointers and memory references, so be very careful when modifying files, names, and directories.
